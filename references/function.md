# /`function`

> 运行一个函数。

**加入版本：** 1.8.0.8

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 无 |

## 语法

```
function <name: filepath>
```

## 参数详解

- **`name`**:filepath - 指定要执行的函数文件路径，例如 path/to/function/file 会定位到[行为包]/functions/path/to/function/file.mcfunction。可以使用双引号"包裹路径，路径名内不允许存在~、!、@等符号。
