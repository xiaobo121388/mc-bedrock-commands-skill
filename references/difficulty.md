# /`difficulty`

> 设定世界难度等级。

**加入版本：** 1.0.5.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 无 |

## 语法

```
difficulty <difficulty: Difficulty> | difficulty <difficulty: int>
```

## 参数详解

- **`difficulty`**:Difficulty/int - 新的游戏难度。必须为以下之一：peaceful (p或0), easy (e或1), normal (n或2), hard (h或3)
