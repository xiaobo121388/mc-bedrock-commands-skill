# /`help`

> 获取可用命令列表或单个命令的帮助信息。

**加入版本：** 0.16.0

| 属性 | 值 |
|---|---|
| **别名** | `?` |
| **权限等级** | 0 |
| **需要作弊** | 否 |
| **额外说明** | 无 |

## 语法

```
help <command: CommandName> | ? <command: CommandName> | help [page: int] | ? [page: int]
```

## 参数详解

- **`command`**:CommandName: basic_string - 指定要提供帮助的命令名称
- **`page`**:int: int - 指定要展示的命令列表的页码
