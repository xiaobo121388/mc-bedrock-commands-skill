# /`project`

> 该命令包含用于管理编辑器项目的工具。

**加入版本：** 1.19.80.20

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 仅在编辑器中可用。 |

## 语法

```
project export <exportType: ExportTypes>
```

## 参数详解

- **`exportType`**:enum - 指定导出内容的类型，可用值有：project — 项目, template — 世界模板, world — 世界
