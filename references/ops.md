# /`ops`

> 授予或移除玩家的操作员状态。

| 属性 | 值 |
|---|---|
| **别名** | `permission` |
| **权限等级** | 仅服务器控制台 |
| **需要作弊** | 否 |
| **额外说明** | 此指令用于在服务器控制台中将玩家提升为操作员。它与 /deop 指令相对应。在游戏内，权限管理通常通过 /permission 指令完成。 |

## 语法

```
op <player: target>
```

## 参数详解

- **`player`**:target: CommandSelector<Player> - 必须为玩家名或目标选择器，指定要授予操作员状态的玩家。
