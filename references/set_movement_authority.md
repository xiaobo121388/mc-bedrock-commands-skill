# /`set_movement_authority`

> 控制客户端或服务端检查玩家的移动。

**⚠️ 注意：该指令在 1.21.50.20 版本加入，属于 1.20.50 之后的较新指令。**

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 该命令已在基岩版1.21.60.27中被移除，并且在正式版中不可用。 |

## 语法

```
set_movement_authority <client|server>
```

## 参数详解

- **`<client|server>`**:字符串 - 指定由客户端还是服务端来检查玩家的移动，必须为'client'或'server'
