# /`clear`

> 清除玩家物品栏的物品。

**加入版本：** 1.0.5.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 在基岩版中，还可以清除光标持有的、来自物品栏的物品。 |

## 语法

```
clear [player: target] [itemName: Item] [data: int] [maxCount: int]
```

## 参数详解

- **`player`**:target - 指定要被清除物品的玩家，如果未指定，默认为命令执行者
- **`itemName`**:Item - 指定要被清除的物品，如果未指定，默认为所有物品
- **`data`**:int - 指定要被清除物品的数据值，如果未指定或为-1，则不考虑物品的数据值
- **`maxCount`**:int - 指定要被清除物品的最大值，如果未指定或为-1，则默认清除所有符合要求的物品，如果为0，则不会清除物品，而是返回指定物品的数量。
