# /`xp`

> 给予或移除玩家的经验值或经验等级。

**加入版本：** 0.16.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 无 |

## 语法

```
xp <amount: int> [player: target] | xp <amount: int>L [player: target]
```

## 参数详解

- **`amount`**:int - 指定要给予或移除的经验值或经验等级。在数字后添加“L”可操作经验等级，否则操作经验值。
- **`player`**:target - 指定目标玩家，如果未指定，则默认为命令执行者。
