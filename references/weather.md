# /`weather`

> 更改游戏中的天气。在基岩版中，也可用于显示当前天气。

**加入版本：** 0.16.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 在基岩版中，duration参数在1.18.30版本后单位从秒变为了游戏刻。 |

## 语法

```
weather <clear|rain|thunder> [duration: int] | weather query
```

## 参数详解

- **`clear|rain|thunder`**:字符串 - 将天气设为晴天、雨天或雷暴雨
- **`duration`**:整数 - 指定天气的持续时间，以游戏刻为单位，范围为0到1000000
- **`query`**:字符串 - 查询当前天气
