# /`kick`

> 将玩家踢出服务器。

**加入版本：** 1.16.0.57

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 否 |
| **额外说明** | /kick命令不再能踢出服务器的拥有者。自1.17.0.54版本起，该指令可在未开启作弊时执行。自1.21.60.23版本起，该指令再次允许使用目标选择器。 |

## 语法

```
kick <name: target> <reason: message>
```

## 参数详解

- **`name`**:target: CommandSelector<Player> - 指定要踢出的玩家。必须为玩家名、目标选择器或玩家的XUID（Xbox UID）。
- **`reason`**:message: CommandMessage - 指定将显示给被踢出玩家的消息。必须为文本，命令的剩余部分全部视作该参数，可以包含空格与目标选择器。
