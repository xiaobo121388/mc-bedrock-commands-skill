# /`daylock`

> 锁定或解锁终为白日。

**加入版本：** 1.2.0.2

| 属性 | 值 |
|---|---|
| **别名** | `alwaysday` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 本条目所述内容仅适用于基岩版和​教育版。 |

## 语法

```
daylock [lock: Boolean]
```

## 参数详解

- **`lock`**:Boolean - 指定是否锁定终为白日。必须为true或false，默认为true。若为false，将同时打开昼夜更替，反之亦然，并同时设置游戏时间为5000刻，游戏正午前1小时。
