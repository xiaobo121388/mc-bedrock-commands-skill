# /`op`

> 给予玩家管理员身份。

**加入版本：** 携带版Alpha 0.16.0 build 1

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 2 |
| **需要作弊** | 是 |
| **额外说明** | 在基岩版中，此命令将玩家在“玩家权限”屏幕中的权限改为“操作员”。在专用服务器中，玩家还会被记录在permissions.json文件里。permissions.json文件可以由/permission命令重新加载。 |

## 语法

```
/op <player: target>
```

## 参数详解

- **`player`**:target: CommandSelector<Player> - 必须为玩家名或目标选择器。且要求目标选择器为玩家类型，若不是则在命令执行时会执行失败。
