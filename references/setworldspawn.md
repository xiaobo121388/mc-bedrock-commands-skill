# /`setworldspawn`

> 设置世界出生点。

**加入版本：** 0.16.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 1.21.100 之前仅支持主世界；1.21.100 起也支持在末地（The End）设置。 |

## 语法

```
setworldspawn [spawnPoint: x y z]
```

## 参数详解

- **`spawnPoint`**:x y z: CommandPositionFloat - 指定世界出生点坐标。若没有指定，默认为命令执行位置所在的方块位置。必须为三维坐标，元素为单精度浮点数。允许使用相对坐标（~ ~ ~）或局部坐标（^ ^ ^）。
