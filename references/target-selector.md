# 目标选择器

目标选择器用于选定符合指定条件的实体。

## 格式

```
<选择器类型>[选择器参数=值, 选择器参数=值]
```

示例：`@e[name=xlwt]` — 选定所有名为 "xlwt" 的实体。

- 仅填写选择器类型 `@xxx`：语法正确
- 仅填写选择器参数 `[]`：语法错误
- 类型+参数 `@xxx[...]`：语法正确

选择器不能独立成命令，仅在需要填写选择器的命令的对应位置使用。选择器参数写在选择器类型后的半角方括号内。选择器内所有标点符号（逗号/等号/下划线/斜杠等）都需使用半角（英文）符号。

基岩版中选择器类型与参数之间可以添加空格但不建议（如 `@a [name=xlwt]`）。

## 选择器类型

| 类型 | 描述 | 备注 |
|---|---|---|
| `@a` | 当前存档的全部玩家 | |
| `@e` | 当前存档的全部实体 | |
| `@s` | 执行指令实体 | 命令方块执行时使用 @s 报错（execute 外套除外） |
| `@p` | 距离执行指令实体最近的玩家 | |
| `@n` | 距离执行指令实体最近的存活实体 | 1.21.100+ 加入 |
| `@r` | 随机玩家 | 基岩版 source type 参数可选定实体类型 |
| `@c` | 玩家的智能体（Agent） | 仅教育版 |
| `@v` | 选择全部智能体（Agent） | 仅教育版 |
| `@initiator` | 选择正在与当前 NPC 交互的玩家 | 仅在 NPC 界面内使用 |

其他可填写在选择器处但不能添加参数的用法：

- `*` — 任意计分板中有分数记录的全部实体（scoreboard 命令中包括虚拟玩家）
- `@here` — 仅聊天栏使用，类似"@全体成员"效果
- `<玩家名称>` — 直接填写玩家名称，仅可选中在线且存活的玩家

## 选择器参数

用于在选择器类型的基础上进一步筛选。多个参数用英文逗号分隔，多项参数将筛选出同时符合所有条件的实体。

### c [仅基岩版]

选择顺序和最大选中数量。正数由远及近，负数由近及远。对于 `@r`，此参数决定是否随机选取多个符合条件的实体。

可用值：-2147483648 ~ 2147483647 整数（不含 0）

示例：`c=3` — 最多选择 3 个最近实体

### x / y / z

选择器执行时计算的坐标偏移。

示例：`x=1,y=2` — x 轴偏移 1，y 轴偏移 2

### dx / dy / dz

坐标偏移量，用于选择指定坐标范围内的实体。

示例：`dx=3` — x 轴偏移 3 格；`dy=-1,dz=2` — y 轴偏移 -1 格，z 轴偏移 2 格

### scores

计分板分数筛选。

| 语法 | 含义 |
|---|---|
| `scores={a=1}` | 计分板 a 分数为 1 |
| `scores={a=1..}` | 计分板 a 分数 ≥ 1 |
| `scores={a=..1}` | 计分板 a 分数 ≤ 1 |
| `scores={a=1..2}` | 计分板 a 分数在 1~2 之间（闭合） |

### distance [仅 Java 版 1.13+]

半径范围。可用值：正整数或范围。

示例：`distance=10`（距离为 10）；`distance=10..20`（半径 10~20）；`distance=10..`（半径 > 10）；`distance=..10`（半径 < 10）

### r / rm [仅基岩版 & Java 版 1.12-]

最大半径 `r` 与最小半径 `rm`。

示例：`r=10` — 最大半径 10；`rm=10` — 最小半径 10

### limit [仅 Java 版]

选中实体的最大数量（与基岩版 c 类似）。可用值：1~2147483647 整数。

示例：`limit=3` — 最多选择 3 个实体

### level [仅 Java 版]

经验等级范围。可用值：1~2147483647 整数。

示例：`level=10`（等级 10）；`level=10..20`（10~20 级）；`level=10..`（≥10 级）

### l / lm [仅基岩版]

最大经验等级 `l` 与最小经验等级 `lm`。可用值：0~2147483647 整数。

示例：`l=10` — 经验等级 ≤ 10；`lm=10` — 经验等级 ≥ 10

### gamemode [仅 Java 版] / m [仅基岩版]

游戏模式筛选，可反选。

Java 版可用值：survival, creative, adventure, spectator（不可简写）

基岩版可用值：

| 模式 | 全称 | 数字 | 简写 |
|---|---|---|---|
| 生存 | survival | 0 | s |
| 创造 | creative | 1 | c |
| 冒险 | adventure | 2 | a |
| 默认 | default | - | d |
| 旁观者 | spectator | - | - (1.19.80+) |

### team [仅 Java 版]

队伍筛选，可反选。

示例：`team=a`（属于队伍 a）；`team=!a`（不属于队伍 a）；`team=`（属于任何队伍）；`team=!`（不属于任何队伍）

### tag

标签筛选，可反选。添加/移除标签需使用 tag 命令。

示例：`tag=a`（拥有标签 a）；`tag=!a`（没有标签 a）；`tag=`（有任意标签）；`tag=!`（没有任何标签）

### name

实体名称筛选，可反选。

示例：`name=xlwt`（名为 xlwt）；`name=!xlwt`（名不为 xlwt）；`name=""`（未命名）；`name=!""`（已命名）

### type

实体类型筛选，可反选。多个反选 type 放在一起则排除它们。

示例：`type=zombie`（僵尸）；`type=!zombie`（非僵尸）

### rx / ry [仅基岩版]

最大垂直旋转角度 `rx` 与最大水平旋转角度 `ry`。

- rx：垂直方向，范围 -90 ~ 90（-90 正上，90 正下）
- ry：水平方向，范围 -180 ~ 180（0 正南，-90 正东，90 正西）

示例：`rx=-89`（抬头）；`ry=0`（小于等于正南）

### rxm / rym [仅基岩版]

最小垂直旋转角度 `rxm` 与最小水平旋转角度 `rym`。

示例：`rxm=-89`（低头）；`rym=0`（大于等于正南）

### x_rotation / y_rotation [仅 Java 版]

垂直旋转角度 `x_rotation` 与水平旋转角度 `y_rotation`，支持范围语法。

示例：`x_rotation=0`（向前地平线）；`x_rotation=30..60`（地平线下方 30~60 度）

### sort [仅 Java 版]

排序方式：nearest（由近至远）、furthest（由远及近）、random（随机）、arbitrary（不排序）

### nbt [仅 Java 版]

实体的数据标签筛选。详见"数据标签"。

### family [仅基岩版]

选择属于/不属于指定族的实体，可反选。

示例：`family=monster` — 选择敌对生物

### hasitem [仅基岩版 1.18.20+]

选择在指定槽位有指定物品的实体。使用 `{}` 包含参数，检测多个物品用 `[{...},{...}]`。

可用参数：

| 参数 | 说明 | 是否必填 |
|---|---|---|
| item | 物品 ID | 必填 |
| data | 物品数据值 | 选填 |
| location | 槽位 ID | 选填 |
| slot | 槽位数据值 | 选填 |
| quantity | 物品数量 | 选填 |

示例：
```
hasitem={item=torch,data=0,location=slot.weapon.mainhand,slot=0,quantity=1}
hasitem=[{item=torch,data=0,location=slot.weapon.mainhand,slot=0,quantity=1..3},{item=turtle_helmet,data=1,location=slot.armor.head,slot=0,quantity=1..3}]
```

### haspermission [仅基岩版 1.19.80+]

选择指定权限状态的玩家。多项权限用英文逗号分隔。

可用权限：camera（相机）、movement（位置移动控制）

可用值：enabled（启用）、disabled（禁用）

格式：`haspermission={camera=enabled,movement=disabled}`

### has_property [仅基岩版 1.20.70+]

筛选实体的指定属性，可检测有/没有指定属性。

示例：`has_property={property=true}`；`has_property={property=!true}`（反选）

对于数字值，可通过 `..` 指定范围，用法与 scores 类似。

### advancements [仅 Java 版]

进度与成就筛选。

示例：`advancements={story/from_obsidian=true}` — 已达成"冰桶挑战"

### predicate [仅 Java 版]

name 选择器的模糊匹配模式。

示例：`predicate=test`（名称含 test）；`predicate=!test`（名称不含 test）
