# /`allowlist`

> 用于管理服务器中的白名单。

**加入版本：** 1.17.0

| 属性 | 值 |
|---|---|
| **别名** | `whitelist` |
| **权限等级** | 4 |
| **需要作弊** | 是 |
| **额外说明** | 仅在专用服务器上可用。自1.18.10版本起，/whitelist 成为 /allowlist 的别名。 |

## 语法

```
allowlist add <name: string> | allowlist list | allowlist reload | allowlist remove <name: string>
```

## 参数详解

- **`name`**:string - 指定要从白名单中添加或删除的玩家名。必须为单个词或者双引号（"）括起的字符串。
