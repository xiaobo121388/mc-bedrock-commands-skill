# /`alwaysday`

> 锁定或解锁终为白日。

**加入版本：** 1.2.0.2

| 属性 | 值 |
|---|---|
| **别名** | `daylock` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 仅适用于基岩版和教育版。若参数设置为false，将同时打开昼夜更替，并设置游戏时间为5000刻。 |

## 语法

```
alwaysday [lock: Boolean]
```

## 参数详解

- **`lock`**:Boolean - 指定是否锁定终为白日。必须为true或false，默认为true。
