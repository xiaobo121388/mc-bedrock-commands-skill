# /`immutableworld`

> 设置世界是否可发生变化。

**加入版本：** 1.5.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 该特性仅在教育版和开启了“Education Edition”选项的基岩版世界中可用。 |

## 语法

```
immutableworld [value: Boolean]
```

## 参数详解

- **`value`**:Boolean - 设置该值以决定世界是否可以发生变化。必须为布尔值（true或false）。
