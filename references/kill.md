# /`kill`

> 杀死生物，清除非生物实体。

**加入版本：** 0.16.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 在基岩版中，尝试使用该命令杀死创造模式下的玩家，只会提示“玩家在创造模式下无法被杀死。”。自1.10.0版本起，/kill不再能杀死创造模式的玩家。 |

## 语法

```
kill [target: target]
```

## 参数详解

- **`target`**:CommandSelector<Actor> - 指定要杀死/清除的目标实体。未指定时，目标为命令的执行者。必须为玩家名或目标选择器。
