# /`save`

> 用于在服务器运行期间为从外部复制备份作准备。

**加入版本：** 1.6.1

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 4 |
| **需要作弊** | 是 |
| **额外说明** | 仅专用服务器端 |

## 语法

```
save hold | save query | save resume
```

## 参数详解

- **`hold`**:无 - 禁用服务器对存档文件的写入，以便于从外部复制存档文件作为备份
- **`query`**:无 - 显示每个存档文件的路径和其应被截断的字节量，以冒号分隔
- **`resume`**:无 - 恢复启用服务器对存档文件的写入
