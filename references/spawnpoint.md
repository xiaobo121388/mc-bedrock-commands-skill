# /`spawnpoint`

> 为特定玩家设置出生点。

**加入版本：** 0.16.0

| 属性 | 值 |
|---|---|
| **别名** | `无` |
| **权限等级** | 1 |
| **需要作弊** | 是 |
| **额外说明** | 现在该命令可以在下界和末地使用。 |

## 语法

```
spawnpoint [player: target] [spawnPos: x y z]
```

## 参数详解

- **`player`**:target: CommandSelector<Player> - 指定被更改出生点的玩家。如果没有指定，默认为命令执行者。必须为玩家名或目标选择器，且目标选择器必须为玩家类型
- **`spawnPos`**:x y z: CommandPositionFloat - 指定玩家新的出生点的坐标。若没有指定，默认为所指定玩家的位置。必须为三维坐标，元素为单精度浮点数，允许使用相对坐标（~）或局部坐标（^）。
